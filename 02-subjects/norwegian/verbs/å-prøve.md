# å prøve (to try)

**Type**: Regular verb
**Infinitive**: å prøve

**Meaning**: To try (attempt or sample/taste)

---

## Presens (Present Tense)

| Person | Norsk | English |
|--------|-------|---------|
| jeg | prøver | I try |
| du | prøver | you try |
| han/hun/det | prøver | he/she/it tries |
| vi | prøver | we try |
| dere | prøver | you try (plural) |
| de | prøver | they try |

### Eksempler (Examples):
- Jeg **prøver** å lære norsk. (I try to learn Norwegian.)
- **Prøver du** denne maten? (Are you trying this food?)
- Hun **prøver** alltid nye ting. (She always tries new things.)
- Vi **prøver** å snakke norsk. (We try to speak Norwegian.)
- De **prøver** ikke fisk. (They don't try fish.)

| Person | Norsk | English |

| jeg | skal prøve / vil prøve | I will try / I'm going to try |

### Eksempler:
- Jeg **skal prøve** å komme. (I will try to come.)
- **Vil du prøve** denne maten? (Will you try this food?)
- Vi **skal prøve** igjen. (We're going to try again.)

---

## Imperativ (Imperative)

**prøv** - try!

### Eksempler:
- **Prøv** dette! (Try this!)
- **Prøv** igjen! (Try again!)
- **Prøv** å forstå. (Try to understand.)

---

## Nektelse (Negation)

Add **ikke** after the verb:

- Jeg **prøver ikke** det. (I don't try that.)
- Vi **prøvde ikke** å ringe. (We didn't try to call.)
- Hun **har ikke prøvd** sushi. (She hasn't tried sushi.)

---

## Nyttige Uttrykk (Useful Expressions)

- **prøve å** + verb - to try to (do something)
  - Jeg **prøver å** lære norsk. (I try to learn Norwegian.)
- **prøve på** - to try on / to try at
  - Kan jeg **prøve på** denne? (Can I try this on?)
- **prøve igjen** - to try again
  - La oss **prøve igjen**! (Let's try again!)
- **prøve seg** - to have a go / give it a try
  - Du må **prøve deg**! (You must give it a try!)

---

## Two Main Uses

### 1. To try (attempt)

- Jeg **prøver** å lære norsk. (I try to learn Norwegian.)
- Vi **prøver** å forstå. (We try to understand.)
- Hun **prøver** å snakke norsk. (She tries to speak Norwegian.)

**Pattern**: prøve + **å** + infinitive

### 2. To try (sample/taste)

- **Prøv** denne maten! (Try this food!)
- Jeg vil **prøve** sushi. (I want to try sushi.)
- **Har du prøvd** norsk brunost? (Have you tried Norwegian brown cheese?)

**Pattern**: prøve + noun (no "å")

---

## Common Uses

**Trying to do something:**
- Jeg **prøver** å lære norsk. (I'm trying to learn Norwegian.)
- Vi **prøver** å snakke norsk. (We try to speak Norwegian.)
- **Prøv** å forstå! (Try to understand!)

**Trying food:**
- **Prøv** dette! (Try this!)
- Jeg vil **prøve** den osten. (I want to try that cheese.)
- **Har du prøvd** rakfisk? (Have you tried rakfisk?)

**Trying again:**
- La oss **prøve** igjen. (Let's try again.)
- **Prøv** en gang til! (Try one more time!)

---

## Important Pattern

**prøve å** + infinitive = try to (do something)

Always use **å** before the next verb:
- Jeg **prøver å** snakke norsk. ✅
- Jeg **prøver** snakke norsk. ❌

This is different from modal verbs!

## Common Things to Try

**Food:**
- **prøve mat** - try food
- **prøve sushi** - try sushi
- **prøve norsk mat** - try Norwegian food
- **prøve brunost** - try brown cheese

**Activities:**
- **prøve å lære** - try to learn
- **prøve å forstå** - try to understand
- **prøve å snakke** - try to speak
- **prøve å lage** - try to make

**Other:**
- **prøve igjen** - try again
- **prøve noe nytt** - try something new
- **prøve seg** - give it a try
