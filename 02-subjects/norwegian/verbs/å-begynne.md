# å begynne (to begin/start)

**Type**: Regular verb
**Infinitive**: å begynne

**Meaning**: To begin, to start

---

## Presens (Present Tense)

| Person | Norsk | English |
|--------|-------|---------|
| jeg | begynner | I begin / I start |
| du | begynner | you begin / you start |
| han/hun/det | begynner | he/she/it begins / starts |
| vi | begynner | we begin / we start |
| dere | begynner | you begin / you start (plural) |
| de | begynner | they begin / they start |

### Eksempler (Examples):
- Jeg **begynner** å arbeide klokken ni. (I start working at 9.)
- **Begynner du** snart? (Are you starting soon?)
- Hun **begynner** på skolen i morgen. (She starts school tomorrow.)
- Vi **begynner** alltid tidlig. (We always start early.)
- De **begynner** møtet nå. (They're starting the meeting now.)

---

## Preteritum (Past Tense)

| Person | Norsk | English |
|--------|-------|---------|
| jeg | begynte | I began / I started |
| du | begynte | you began / you started |
| han/hun/det | begynte | he/she/it began / started |
| vi | begynte | we began / we started |
| dere | begynte | you began / you started (plural) |
| de | begynte | they began / they started |

### Eksempler:
- Jeg **begynte** å arbeide klokken åtte. (I started working at 8.)
- **Begynte du** allerede? (Did you already start?)
- Vi **begynte** møtet for sent. (We started the meeting too late.)
- Hun **begynte** på universitetet i fjor. (She started university last year.)

## Imperativ (Imperative)

**begynn** - begin! / start!

### Eksempler:
- **Begynn** nå! (Start now!)
- **Begynn** med det viktigste! (Start with the most important!)

---

## Nektelse (Negation)

Add **ikke** after the verb:

- Jeg **begynner ikke** ennå. (I'm not starting yet.)
- Vi **begynte ikke** på tide. (We didn't start on time.)
- Hun **har ikke begynt** ennå. (She hasn't started yet.)

---

## Nyttige Uttrykk (Useful Expressions)

- **begynne å** + verb - to start to [verb]
  - Jeg **begynner å** arbeide. (I start to work / I start working.)
  - Vi **begynner å** lære. (We start to learn / We start learning.)
- **begynne på** + noun - to start [noun]
  - Jeg **begynner på** jobben. (I start the job.)
  - Hun **begynner på** skolen. (She starts school.)
- **begynne med** - to start with
  - La oss **begynne med** det enkleste. (Let's start with the easiest.)
- **begynne tidlig** - to start early
  - Vi **begynner tidlig** i dag. (We start early today.)
- **begynne sent** - to start late
  - Møtet **begynner sent**. (The meeting starts late.)

---

## Common Uses

**Starting work or activities:**
- Jeg **begynner** å arbeide klokken ni. (I start working at 9.)
- Hun **begynner** på jobben i morgen. (She starts the job tomorrow.)
- Vi **begynner** møtet nå. (We're starting the meeting now.)

**Starting to learn:**
- Jeg **begynner** å lære norsk. (I'm starting to learn Norwegian.)
- **Begynte du** å studere? (Did you start studying?)
- Vi **har begynt** å forstå. (We have started to understand.)

**Starting activities with specific times:**
- Filmen **begynner** klokken åtte. (The film starts at 8.)
- Skolen **begynner** klokken ni. (School starts at 9.)
- Arbeidsdagen **begynner** tidlig. (The workday starts early.)

---

## Time Prepositions with "begynne"

- **begynne klokken** - start at [time]
  - Jeg **begynner klokken** ni. (I start at 9.)
- **begynne om** - start in/during (part of day)
  - Vi **begynner om morgenen**. (We start in the morning.)
- **begynne på** - start on (day)
  - Jeg **begynner på mandag**. (I start on Monday.)
- **begynne i** - start in (month/year)
  - Hun **begynner i august**. (She starts in August.)

---

## Common Questions

**Når begynner du?** - When do you start?

**Hva tid begynner møtet?** - What time does the meeting start?

**Har du begynt allerede?** - Have you started already?

**Skal vi begynne?** - Shall we start?

**Begynner du snart?** - Are you starting soon?

## Opposite Verb

**å slutte** - to finish / to end (opposite action)
- Jeg **begynner** klokken ni og **slutter** klokken fem. (I start at 9 and finish at 5.)
- Når **begynner** filmen og når **slutter** den? (When does the film start and when does it end?)

---

## Patterns with "begynne"

**begynne å + infinitive** - start to [verb]
- Jeg **begynner å** forstå. (I start to understand.)
- Hun **begynte å** gråte. (She started to cry.)
- Vi **begynner å** arbeide. (We start to work.)

**begynne på + noun** - start [noun]
- Jeg **begynner på** jobben. (I start the job.)
- Han **begynte på** skolen. (He started school.)
- Vi **begynner på** prosjektet. (We start the project.)

**begynne med + noun/verb** - start with
- La oss **begynne med** deg. (Let's start with you.)
- Jeg **begynner med** å lese. (I start by reading.)
- Vi **begynte med** oppgaven. (We started with the task.)

---

## Frequency Adverbs with "begynne"

- **alltid begynne** - always start
  - Jeg **begynner alltid** tidlig. (I always start early.)
- **vanligvis begynne** - usually start
  - Vi **begynner vanligvis** klokken ni. (We usually start at 9.)
- **ofte begynne** - often start
  - Hun **begynner ofte** sent. (She often starts late.)
- **noen ganger begynne** - sometimes start
  - Jeg **begynner noen ganger** tidlig. (I sometimes start early.)
- **sjelden begynne** - rarely start
  - Han **begynner sjelden** før ti. (He rarely starts before 10.)

---

## Special Expressions

**Begynne forfra** - Start over / Start from the beginning
- La oss **begynne forfra**. (Let's start over.)

**Begynne på nytt** - Start anew / Start again
- Vi må **begynne på nytt**. (We must start anew.)

**Det begynner å...** - It's starting to...
- Det **begynner å** regne. (It's starting to rain.)
- Det **begynner å** bli kaldt. (It's starting to get cold.)
- Det **begynner å** bli mørkt. (It's starting to get dark.)

**Begynne for alvor** - Start in earnest / Really start
- Nå **begynner** arbeidet **for alvor**. (Now the work really starts.)
