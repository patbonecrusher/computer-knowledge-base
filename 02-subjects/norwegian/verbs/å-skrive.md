# å skrive (to write)

**Type**: Irregular verb
**Infinitive**: å skrive

---

## Presens (Present Tense)

| Person | Norsk | English |
|--------|-------|---------|
| jeg | skriver | I write |
| du | skriver | you write |
| han/hun/det | skriver | he/she/it writes |
| vi | skriver | we write |
| dere | skriver | you write (plural) |
| de | skriver | they write |

### Eksempler (Examples):
- Jeg **skriver** en bok. (I write a book / I'm writing a book.)
- **Hva skriver du?** (What are you writing?)
- Hun **skriver** brev. (She writes letters / She's writing a letter.)
- Vi **skriver** norsk. (We write Norwegian.)
- De **skriver** ofte. (They write often.)

---

## Preteritum (Past Tense)

| Person | Norsk | English |
|--------|-------|---------|
| jeg | skrev | I wrote |
| du | skrev | you wrote |
| han/hun/det | skrev | he/she/it wrote |
| vi | skrev | we wrote |
| dere | skrev | you wrote (plural) |
| de | skrev | they wrote |

### Eksempler:
- Jeg **skrev** et brev i går. (I wrote a letter yesterday.)
- **Hva skrev du?** (What did you write?)
- Vi **skrev** sammen. (We wrote together.)
- Hun **skrev** en lang tekst. (She wrote a long text.)

---

## Presens perfektum (Present Perfect)

**Pattern**: har + skrevet

| Person | Norsk | English |
|--------|-------|---------|
| jeg | har skrevet | I have written |
| du | har skrevet | you have written |
| han/hun/det | har skrevet | he/she/it has written |
| vi | har skrevet | we have written |
| dere | har skrevet | you have written (plural) |
| de | har skrevet | they have written |

### Eksempler:
- Jeg **har skrevet** mange brev. (I have written many letters.)
- **Har du skrevet** leksene? (Have you written the homework?)
- Vi **har skrevet** en bok. (We have written a book.)
- Hun **har skrevet** til meg. (She has written to me.)

---

## Framtid (Future)

**Pattern**: skal/vil + skrive

| Person | Norsk | English |
|--------|-------|---------|
| jeg | skal skrive / vil skrive | I will write / I'm going to write |
| du | skal skrive / vil skrive | you will write |
| han/hun/det | skal skrive / vil skrive | he/she/it will write |
| vi | skal skrive / vil skrive | we will write |
| dere | skal skrive / vil skrive | you will write (plural) |
| de | skal skrive / vil skrive | they will write |

### Eksempler:
- Jeg **skal skrive** et brev i morgen. (I'm going to write a letter tomorrow.)
- **Vil du skrive** med meg? (Will you write with me?)
- Vi **må skrive** lekser. (We must write homework.)

---

## Imperativ (Imperative)

**skriv** - write!

### Eksempler:
- **Skriv** navnet ditt! (Write your name!)
- **Skriv** her! (Write here!)
- **Skriv** dette! (Write this!)

---

## Nektelse (Negation)

Add **ikke** after the verb:

- Jeg **skriver ikke** mye. (I don't write much.)
- Vi **skrev ikke** brevet. (We didn't write the letter.)
- Hun **har ikke skrevet** ennå. (She hasn't written yet.)

---

## Nyttige Uttrykk (Useful Expressions)

- **skrive et brev** - to write a letter
- **skrive lekser** - to write homework / to do homework
- **skrive en bok** - to write a book
- **skrive til** - to write to (someone)
  - Jeg **skriver til** deg. (I'm writing to you.)
- **skrive om** - to write about
  - Jeg **skriver om** Norge. (I'm writing about Norway.)
- **skrive ned** - to write down
  - Kan du **skrive ned** dette? (Can you write this down?)
- **skrive ut** - to print out / to write out
- **skrive på** - to write in (a language)
  - Jeg kan **skrive på** norsk. (I can write in Norwegian.)

---

## What You Can Write

**brev** = letter (et brev)
- Jeg **skriver et brev**. (I'm writing a letter.)

**bok** = book (en bok)
- Hun **skriver en bok**. (She's writing a book.)

**tekst** = text (en tekst)
- Vi **skriver en tekst**. (We're writing a text.)

**melding** = message (en melding)
- Jeg **skriver en melding**. (I'm writing a message.)

**lekser** = homework (plural)
- Du må **skrive lekser**. (You must write homework / do homework.)

**navn** = name (et navn)
- **Skriv navnet ditt**. (Write your name.)

**Kan du skrive norsk?** - Can you write Norwegian?

**Skriver du ofte?** - Do you write often?

**Skal vi skrive sammen?** - Shall we write together?

- Jeg **skriver til** deg. (I'm writing to you.)

**skrive om** = write about

**skrive på** = write in (a language)

---

## Related Expressions

**Jeg må skrive lekser** - I have to do homework

**Kan du skrive dette ned?** - Can you write this down?

**Hun skriver bøker** - She writes books (as a profession)

**Skriv til meg!** - Write to me!

---

## Special Note: Conjugation

**å skrive** is irregular in past tense:
- Present: skriver
- Past: **skrev** (irregular!)
- Past participle: **skrevet** (irregular!)

---

## Writing vs Typing

In modern Norwegian, **å skrive** can mean:
- **Write by hand**: Jeg **skriver** med penn. (I write with a pen.)
- **Type**: Jeg **skriver** på dataen. (I type on the computer.)

Both are "å skrive"!
