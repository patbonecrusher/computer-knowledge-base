## Usage

Emojis appear in:
1. **H1 headings** - Main title of each file
2. **File content** - When you open a file
3. **Graph view** - Visual distinction between notes
4. **Search results** - Easier to scan

Emojis do NOT appear in:
- File names (to avoid link breakage)
- Folder names
- Link text (unless explicitly included)

## Benefits

✅ **Visual scanning** - Quickly identify note types
✅ **Graph organization** - Easier to see clusters
✅ **Navigation** - Memorable visual markers
✅ **No link breakage** - File names unchanged
