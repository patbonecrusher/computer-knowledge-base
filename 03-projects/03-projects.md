## Project Guidelines

### What is a Project?
- Has a specific goal or deliverable
- Has a completion state
- Time-bound (even if long-term)
- Active work in progress

### What is NOT a Project?
- Ongoing areas of responsibility → Goes in `02-subjects/`
- Reference material → Goes in `01-sources/`
- Completed work → Goes in `04-archive/`

### Project Lifecycle
1. **Active** - Currently working on (lives here in `03-projects/`)
2. **On Hold** - Paused but will resume (stays in `03-projects/` with status tag)
3. **Complete** - Finished! (moves to `04-archive/`)
4. **Abandoned** - No longer pursuing (moves to `04-archive/`)
